# Лабораторна робота №6 • Варіант 5

Swing, анімація та винятки

Автор: Гінчак Максим Богданович, 241-А.

## Завдання

- 1. Відрізок обертається навколо точки, що рухається по відрізку.
- 2. Swing-інтерфейс для матриць лабораторної 1: JFrame, JPanel, JButton, JLabel, JTextField, JTable; читання файлу.
- Обробка IOException, NumberFormatException і власного MatrixSizeException, успадкованого від ArithmeticException.

## Запуск в IntelliJ IDEA

Відкрийте **саме цю папку Lab06** через File → Open → New Window. Це самостійний проєкт, який не потребує сусідніх лабораторних. Оберіть JDK 17+ у File → Project Structure → Project SDK. На підготовленому Mac вже налаштовано `JBR-25-labs`.

У списку конфігурацій виберіть `Lab06_Main` і натисніть Run. Робоча тека - корінь цього проєкту.

## Запуск у терміналі

```sh
./run.sh
./test.sh
```

Скрипти беруть JDK із JAVA_HOME, установленої IntelliJ або PATH. Для Windows: створіть папку out, виконайте `javac -encoding UTF-8 --release 17 -d out src/*.java`, потім `java -cp out Main` (у PowerShell перелік файлів можна передати через `Get-ChildItem src -Filter *.java`).

## Демонстрація

1. На вкладці анімації поясни окремі рухи точки та синього відрізка.
2. На вкладці матриць «Обчислити X» дає [1,0]. Прочитай data/matrices.txt і зміни клітинку.
3. n=16 демонструє власний виняток; data/bad-format.txt - помилку формату; неіснуючий шлях - IOException.

## Уточнення умови

- Рухома точка лежить на окремому горизонтальному напрямному відрізку; синій відрізок обертається навколо неї.
- Описку JLable виправлено на JLabel.
- Файл: n, потім рівно 2*n*n чисел, спочатку A по рядках, потім B.
